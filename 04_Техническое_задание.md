## Назначение и функции

Система предназначена для автоматизации учёта выдачи книг на абонементе библиотеки. Пользователь — библиотекарь. Основание — Устав проекта (docs/01_Устав_проекта.md).
Обязательные функции: 
* FR-1: Добавление книги (название, автор).
* FR-2: Выдача книги читателю (ID книги, ФИО читателя, дата).
* FR-3: Поиск книги по названию.
* FR-4: Отметка возврата книги.
* FR-5: Отображение списка всех книг с актуальным статусом.

## Интерфейс

- Интерфейс: одно главное окно Tkinter. Слева — вертикальная панель кнопок действий. В центре — таблица (Treeview) со всеми книгами. Внизу — поле поиска.
- Действия: кнопки «Добавить», «Выдать», «Найти», «Возврат». Поиск по названию срабатывает по нажатию кнопки «Найти». Подтверждение критических действий (возврат) через `messagebox.askyesno`.
- Ошибки: при вводе пустых полей или неверного ID книги появляется `messagebox.showerror` или `showwarning` с текстом ошибки. Программа не падает, а ожидает корректного ввода.
- Макеты: интерфейс реализован согласно коду в `main.py`. Скриншоты рабочего окна будут добавлены в папку `docs/images/` перед сдачей проекта.

## Данные и реализация

- Стек: Python 3.11+; библиотека Tkinter (встроенная). Внешние зависимости отсутствуют.
- Запись (Книга): 
  - `id` (int) — уникальный идентификатор (обязателен, автоинкремент).
  - `title` (str) — название книги (обязательное поле).
  - `author` (str) — автор книги (обязательное поле).
  - `reader` (str или None) — имя читателя (пусто, если книга в библиотеке).
  - `date` (str или None) — дата выдачи в формате ДД.ММ.ГГГГ.
- Пример: Книга — ID: 1, Название: «Мастер и Маргарита», Автор: «М.А. Булгаков», Читатель: "", Дата: "".
- Хранение: список словарей Python в оперативной памяти. При запуске программы данные загружаются из файла `library_data.json`. При закрытии — сохраняются в него. Если файл отсутствует, создается новый пустой список.
- Правила: 
  - Название и автор не могут быть пустыми.
  - Дата выдачи при заполнении должна соответствовать формату ДД.ММ.ГГГГ (проверяется через `datetime.strptime`).
  - ID книги уникален.
  - Нельзя выдать книгу, которая уже имеет статус «выдана» (она исключается из списка выбора).
