# Устав проекта

**Проект:** Система учёта выдачи книг в библиотеке. **Заказчик:** MyProject. **Автор:** Аникин Олег, 12ТЭС.
**Версия документа:** 1.0. **Дата:** 19.11.2026.

## Цель и задачи

- **Цель:** создать десктопное приложение (GUI) для библиотекаря, которое позволит сократить время поиска информации о выданных книгах и исключить ошибки при выдаче.
- **Измеримый результат:** находить книгу по названию за 5 секунд; выдавать книгу читателю (с вводом данных) за 20 секунд на тестовом наборе из 10 книг.
- **Задачи:** 
  1. Выяснить требования и согласовать функционал.
  2. Описать поля данных (книга, читатель, дата) и нарисовать интерфейс.
  3. Реализовать функции добавления, выдачи, поиска и возврата.
  4. Провести ручное тестирование и подготовить инструкцию по запуску.

## Участники и границы

- **Заказчик:** MyProject.
- **Пользователи и их интересы:** 
  - *Библиотекарь:* быстро находит книгу, видит, у кого она на руках, не допускает двойную выдачу.
  - *Студент/читатель:* получает книгу без задержек.
- **Исполнитель:** Аникин Олег; роли — аналитик, разработчик, тестировщик.
- **Входит (версия 1.0):** 
  1. Добавление книги (название, автор).
  2. Выдача книги (выбор ID, ввод читателя и даты).
  3. Поиск по названию.
  4. Отметка возврата.
  5. Отображение списка в таблице.
  6. Сохранение данных в JSON-файл.
- **Не входит (версия 1.0):** 
  - Реляционная база данных (SQL).
  - Авторизация пользователей (роли администратора/библиотекаря).
  - Печать формуляров.
  - Автодополнение при поиске.

## Критерии успеха

- Приложение запускается на чистом компьютере по инструкции в `README.md` без дополнительных настроек.
