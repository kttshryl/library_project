## Назначение

Приложение создано для автоматизации работы библиотекаря на абонементе. Оно решает задачу быстрого учёта выдачи и возврата книг, заменяя бумажный журнал. Цель — исключить ошибки двойной выдачи и сократить время поиска информации о том, у какого читателя находится книга.

## Установка и запуск

1. **ОС, версия Python и необходимые компоненты:** Windows 10/11, Linux (Ubuntu/Debian) или macOS. Python 3.11 или новее. Внешние библиотеки не требуются, используется встроенный Tkinter.
2. **Откуда скачать и куда распаковать приложение:** скачать ZIP-архив репозитория с платформы и распаковать в любую папку на компьютере (например, `C:\Projects\library_project`).
3. **Команда запуска:** 
   - Открыть терминал (командную строку) в папке проекта.
   - Выполнить команду: `python main.py`.
4. **Демонстрационные данные для ввода:**
   - *Книга 1:* «Война и мир», автор «Л.Н. Толстой».
   - *Книга 2:* «Преступление и наказание», автор «Ф.М. Достоевский».
   - *Выдача:* выбрать ID 1, читатель «Иванов А.А.», дата «15.11.2026».

## Основные сценарии

- **Добавить книгу:** нажать кнопку «Добавить книгу» → в появившихся окнах ввести название и автора → нажать OK → книга появится новой строкой в таблице с пустыми полями «Читатель» и «Дата».
- **Найти книгу:** ввести часть названия (например, «Война») в поле поиска → нажать кнопку «Найти» → в таблице отобразятся только подходящие книги. Чтобы сбросить фильтр, очистить поле поиска и снова нажать «Найти» или перезапустить программу.
- **Изменить данные или статус (Выдать/Вернуть):** 
  - *Выдать:* нажать «Выдать книгу» → выбрать ID из списка свободных книг → ввести имя читателя и дату.
  - *Вернуть:* нажать «Отметить возврат» → выбрать ID выданной книги → подтвердить действие в диалоговом окне.
- **Завершить работу:** нажать на крестик закрытия окна. Приложение автоматически сохранит данные в файл `library_data.json`. При следующем запуске данные загрузятся обратно.

## Частые вопросы

- **Запись не добавляется.** Проверьте, что поля «Название» и «Автор» не пустые. Программа не создает запись без этих данных.
- **Ничего не найдено.** Поиск регистронезависимый (не важно, большие или маленькие буквы). Убедитесь, что вы не ввели лишние пробелы. Нажмите кнопку «Найти» с пустым полем, чтобы сбросить фильтр.
- **Почему после закрытия исчезли записи?** В первой версии это было бы так, но в текущей реализации (v1.0) данные сохраняются в файл `library_data.json` автоматически. Если файл был удален вручную, при запуске создастся новый пустой список.
