# Требования

**Проект:** Система учёта выдачи книг в библиотеке. **Заказчик:** MyProject. **Автор:** Аникин Олег, 12ТЭС.
**Версия документа:** 1.0. **Дата:** 19.11.2026.

## Бизнес-требования

- BR-1: сократить время поиска информации о местонахождении книги и исключить ошибки двойной выдачи.
- BR-2: обеспечить библиотекарю и читателю актуальную информацию о статусе книги (свободна/выдана).
- Показатель результата: время поиска книги по названию сокращено с 2–3 минут (поиск в журнале) до 5–10 секунд; количество ошибок выдачи сведено к нулю на тестовом наборе из 20 записей.

## Функциональные требования

- FR-1: система позволяет добавить книгу, указав название и автора.
- FR-2: система позволяет выдать книгу, указав ID книги, имя читателя и дату выдачи.
- FR-3: система позволяет найти книгу по части названия или имени автора (поиск регистронезависимый).
- FR-4: система позволяет отметить возврат книги, очищая поля читателя и даты.
- FR-5: система отображает актуальный список всех книг в таблице, подсвечивая статус (выдана/свободна).
- FR-6: система сохраняет все данные в файл `library_data.json` при закрытии и загружает их при запуске.
- FR-7: система предотвращает выдачу книги, которая уже числится за другим читателем (скрывает выданные книги из списка выбора).

## Нефункциональные требования и ограничения

- NFR-1: интерфейс должен отзываться без задержек; список из 50 записей должен обновляться менее чем за 1 секунду.
- NFR-2: при вводе пустых полей (название, автор) или неверного формата даты (не ДД.ММ.ГГГГ) система показывает понятное сообщение об ошибке и блокирует создание/изменение записи.
- NFR-3: приложение должно запускаться на Windows, Linux и macOS при наличии Python 3.11+; интерфейс должен быть читаемым (шрифт не менее 10pt).
- **Ограничения:** 3 спринта по 2 недели; один разработчик; стек Python + Tkinter; хранение данных — список словарей в памяти с синхронизацией в JSON; база данных (SQL) не используется.
- **Дополнительно по желанию:** печать формуляра книги, статистика по самым активным читателям.
- **Приоритеты:** 
  - *Обязательно (MVP):* FR-1, FR-2, FR-5, FR-6, NFR-1, NFR-2.
  - *Желательно:* FR-3, FR-4, FR-7.
  - *По возможности:* дополнительные функции из раздела выше.
